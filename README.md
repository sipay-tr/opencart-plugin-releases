# Sipay OpenCart Plugin — Releases

This repository hosts the official downloadable releases of the **Sipay OpenCart payment extension**. Download a ready-to-install `.zip` package from the Releases page below.

## Download the latest release

1. Open the [**Releases**](https://github.com/sipay-tr/opencart-plugin-releases/releases/latest) page.
2. Download the **`sipay-opencart-plugin-<version>.zip`** file under the latest release.

## Installation

1. In the OpenCart admin, go to **Extensions → Installer**.
2. Under **Upload**, choose the downloaded **`sipay-opencart-plugin-<version>.zip`** and wait for the upload to complete.
3. Go to **Extensions → Modifications** and click **Refresh** (top-right) to apply the changes.
4. Go to **Extensions → Extensions** and select **Payments** from the *Choose the extension type* dropdown.
5. Find **Sipay** in the list, click **Install** (the green **+**), then click **Edit** (the blue pencil) to open its settings.
6. Enter your Sipay API credentials, set the status to **Enabled**, and click **Save**.

> To update, repeat the same steps with the newest `.zip`; OpenCart installs it over the existing files.

## Requirements

- OpenCart **3.0.x.x**.
- PHP **7.0** or higher with the cURL extension enabled.
- A valid Sipay merchant account and API credentials.
